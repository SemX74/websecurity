CSRF Attack Simulator

This page simulates a malicious website that attempts to perform a CSRF attack against your application.

How CSRF Attacks Work

  1. The victim is authenticated to the target website
  2. The victim visits a malicious website
  3. The malicious website contains code that sends a request to the target website
  4. The browser includes the victim's authentication cookies with the request
  5. If there's no CSRF protection, the target website processes the request as legitimate

Malicious Form (Auto-Submit)

This form automatically submits when the page loads. In a real-world scenario, this could be hidden from the user or disguised as something else.

Why This Attack Fails

With CSRF protection enabled in Spring Security, this attack will fail because:

  1. The server expects a valid CSRF token in the request
  2. The attacker doesn't have access to the victim's CSRF token
  3. Without a valid token, the server rejects the request
